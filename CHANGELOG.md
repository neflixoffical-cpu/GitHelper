# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-09

### Добавлено
- Анимированная заставка: диагональное проявление логотипа, блик, загрузка с проверками
- Тема `color 9`: светло-синий на чёрном с градиентами
- Установка Git через `winget` при первом запуске
- Вход в GitHub по почте и паролю (официальное окно GitHub, 2FA) и по токену
- Хранение токена в Диспетчере учётных данных Windows
- Мастер публикации: папка → `.gitignore` → коммит → репозиторий → push
- `.gitignore`: автоопределение стека, 16 встроенных шаблонов, 200+ шаблонов GitHub, интерактивное дерево файлов
- Проверка на секреты и файлы > 100 МБ перед коммитом
- Conventional Commits, автогенерация сообщения
- Ветки, история-граф, stash, синхронизация
- Исправление ошибок: отмена коммита, amend, откат файлов, revert, reflog
- Релизы с semver-подсказкой и заметками из коммитов
- Генерация README и LICENSE
- Статистика репозитория, клонирование, быстрые ссылки на GitHub
